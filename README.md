# Unity-chan Action TD — Web Preview

Live preview: https://kikutadev.github.io/3d-unity-chan-td-web/

Public GitHub Pages build used only for hands-on control/feel review.

- Source revision: `cf3b95c`
- Unity: `6000.3.22f1`
- Build target: WebGL
- Compression: Brotli with Unity decompression fallback for static hosting
- Source project is intentionally **not** mirrored here. This repository contains the generated playable build and public deployment metadata only.

## Desktop controls

`WASD` move · `Space` jump · `J` attack · `K` strong/launcher · `L` dodge · `Q` special · `1/2/3` direct-deploy Delay/Gather/Amplify · `R` replay after victory/defeat.

## Mobile controls

Landscape touch layout: left thumb movement, right thumb combat/jump, persistent `DLY/GTH/AMP` support dock. Support is one-tap nearest-valid deploy and does not consume Combat Energy.
